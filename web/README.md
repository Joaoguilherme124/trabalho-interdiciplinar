# Vitrine — Marketplace (telas)

SPA visual do marketplace com React, Tailwind CSS e Lucide Icons.

## Rodar

```bash
cd web
npm install
npm run dev
```

Abra o endereço que aparecer no terminal (geralmente `http://localhost:5173`).

## Telas

- **/** — Vitrine (busca, chips de categoria, lojas, produtos, carrinho)
- **/loja/:id** — Página individual da loja
- **/dashboard** — Portal do lojista (métricas, tabela, modais de cadastro)
- Alternância **claro/escuro** no header
